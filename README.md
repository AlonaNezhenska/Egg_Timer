# 🥚 Egg Timer

A cheerful desktop egg timer built with JavaFX. Pick how you like your egg, press start and a live countdown takes care of the rest.

![Java](https://img.shields.io/badge/Java-17-ED8B00?style=flat-square&logo=openjdk&logoColor=white)
![JavaFX](https://img.shields.io/badge/JavaFX-17-007396?style=flat-square)
![Maven](https://img.shields.io/badge/Build-Maven-C71A36?style=flat-square&logo=apachemaven&logoColor=white)

## ✨ Features

- 🍳 Choose from four egg styles, each with its own cooking time
- ⏱️ Smooth countdown driven by a JavaFX `AnimationTimer` and `java.time.Duration`
- 🎨 Custom styled buttons with hover animations and drop shadows
- 🖼️ Illustrated multi window flow: welcome screen, egg picker, then the timer

## ▶️ Run it

```bash
./mvnw clean javafx:run
```

Run from the project root so the images in `src/main/resources/images` load correctly.
